# Smart Water Purification and Quality Monitoring System

An ECE application development project from Malla Reddy University, Hyderabad.

## Project overview

This project combines a multi-stage water filtration unit with sensor-based monitoring. The presentation describes sediment/cotton filtration, activated carbon, a pH probe and sensor module, an ESP32 controller, and LED/buzzer status indication.

The system flow is:

1. Raw water enters the filtration unit.
2. Sediment/cotton filtration removes larger suspended particles.
3. Activated carbon helps reduce odor and color.
4. The pH probe senses acidity/alkalinity.
5. The ESP32 reads and evaluates the sensor signal.
6. An LED/buzzer indicates PASS or ALERT according to the configured project threshold.

> **Important limitation:** A pH reading alone does not establish that water is safe to drink. The supplied presentation also identifies TDS, turbidity, and temperature sensing as possible extensions.
